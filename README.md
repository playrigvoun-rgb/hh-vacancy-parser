## Это универсальный парсер, который находит вакансии на hh.ru. Есть фильтры: по названию вакансии(пример: учитель,    менеджер и т.д.), по региону поиска(пример: Москва, Ростов-на-Дону и т.д.), по количеству страниц, которые нужно    запарсить(пример: 10, 20, 50 и т.д.).

## Возможности
- Поиск по ключевым словам (название вакансии)
- Выбор региона (любой город РФ)
- Настройка количества страниц для парсинга
- Автоматическая пагинация
- Сохранение в Excel (название, компания, зарплата, адрес)

## Как использовать
1. Установи зависимости: `pip install -r requirements.txt`
2. Запусти скрипт: `python hh.py`/`python3 hh.py`
3. Введи параметры: название вакансии, город, количество страниц.

## Структура проекта
- `hh.py` — основной скрипт
- `requirements.txt` — зависимости
- `jobs_hh_python.xlsx` — результат парсинга (создаётся автоматически)
